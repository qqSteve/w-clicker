# W Clicker

Небольшой кликер для Windows: удерживает клавишу **W** и нажимает левую кнопку мыши **раз в секунду**. Работает из одного файла `WClicker.exe`, установка и Python не нужны.

## Скачать и запустить

1. Откройте [последний релиз](https://github.com/qqSteve/w-clicker/releases/latest) и скачайте `WClicker.exe`.
2. Запустите файл. Программа откроется в остановленном состоянии.
3. Переключитесь в нужное окно и наведите курсор на место клика.
4. Нажмите **F6**, чтобы начать.

| Клавиша | Действие |
| --- | --- |
| **F6** | Запуск; во время работы — пауза; на паузе — продолжение |
| **F8** | Полная остановка |
| **F10** | Остановка и выход из программы |

Горячие клавиши работают, когда открыто другое приложение. Также доступны кнопки в окне кликера. При паузе, остановке и закрытии окна программа отпускает W. Первый клик происходит сразу после запуска или продолжения, последующие — с интервалом 1 секунда. Клики выполняются в текущем положении курсора.

При запуске и продолжении через F6 окно кликера автоматически сворачивается. Пауза и стоп не разворачивают его; состояние видно по заголовку окна на панели задач.

Программа нажимает физическую клавишу W, поэтому работает независимо от выбранной раскладки клавиатуры. Не удерживайте W вручную одновременно с кликером.

## Требования

- Windows 10/11, 64-разрядная версия.
- Доступные глобальные клавиши F6, F8 и F10. Если их заняла другая программа, кликер сообщит об этом и не запустит автоматический ввод.
- Целевое приложение должно принимать стандартный ввод Windows. Приложения с правами администратора могут не принимать ввод от программы, запущенной с обычными правами.

## Проверка скачанного файла

В релизе есть файл `SHA256SUMS.txt`. Чтобы вычислить контрольную сумму в PowerShell:

```powershell
Get-FileHash .\WClicker.exe -Algorithm SHA256
```

Сравните значение `Hash` с опубликованным в `SHA256SUMS.txt`.

## Сборка из исходников

Нужен Visual Studio 2022 или Build Tools for Visual Studio с компонентом **Desktop development with C++** и Windows SDK. В корне проекта выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

Скрипт найдёт MSVC, соберёт программу и запустит тесты. В том числе проверит, что окно приложения открывается и нормально закрывается, без нажатий клавиш и кликов мышью. Готовый файл появится в `dist\WClicker.exe`, контрольная сумма — в `dist\SHA256SUMS.txt`. Для сборки без запуска тестов используйте параметр `-SkipTests`.

Исходники не используют сторонние библиотеки: C++17 и Windows API. Среда выполнения C++ включена в исполняемый файл статически.

GitHub Actions выполняет сборку и тесты на Windows при отправке изменений, создании pull request или ручном запуске workflow. Результат доступен в артефакте `WClicker-windows-x64`.
